# ICPC Tools vs XCPCIO：差在哪

> 对着 `v2.6.1331` 源码和 `presentations.xml` 逐项核过的，不是印象。

## 一句话

**不是同类工具。** ICPC Tools 是「赛场大屏播放器」，XCPCIO 是「榜单渲染器」。
后者是前者的一小块（Scoreboard 分类里的 1 个画面）。

## 体量对比

ICPC Tools **75 个画面**，分 12 类：

| 分类 | 数量 | 内容 |
| --- | --- | --- |
| ICPC | 12 | 题目汇总、单队、照片、题色、气球路径、校徽墙/淡入/滑动、解说、队伍详情 |
| Scoreboard | 9 | 总榜、时间线、判题队列、队伍判题、首解、**一血**、Leaderboard、分组榜 ×2 |
| Chart | 9 | 语言、题目明细/对比/汇总、榜单变化、总题数、判题耗时、历史对比、队列深度 |
| Logos and Messages | 8 | Logo ×3、图片渐变、消息、宣传、CCS、ICPC Tools 标志 |
| Resolver | 7 | 滚榜：Splash、剩余学校、颁奖 ×3、队标 |
| Clock | 4 | 比赛时钟、倒计时、**带工位状态的倒计时**、圆形倒计时 |
| Tile Scoreboards | 4 | 磁贴榜 ×4 |
| Maps | 4 | 世界地图、分组地图、队伍介绍、提交地图 |
| Fun | 4 | 烟花、Bill Poucher、勿动、Mohamed |
| Team | 5 | 选手机位相关（桌面/同步/视频/Snake） |
| Test | 6 | 自检画面（对齐、同步、BSOD、FPS） |
| Beta | 3 | 更好的烟花、赛场地面 |

XCPCIO 侧（`packages/apps/board`）：**一个榜单视图** + 排名算法。

## 能力差

| 能力 | ICPC Tools | XCPCIO Board |
| --- | --- | --- |
| 榜单（12 行分页滚动） | ✅ | ✅（更现代，自适应） |
| 判题队列（每提交一行队伍） | ✅ | ❌ |
| 一血 / 首解 | ✅ | ❌ |
| 题目汇总（色块） | ✅ | ❌ |
| 柱状图 / 折线图 | ✅ 9 种 | ❌ |
| 倒计时（含工位状态） | ✅ 4 种 | ❌ |
| 滚榜 Resolver | ✅ | ⚠️ 有独立实现 |
| 校徽墙 / 照片 / 宣传位 | ✅ | ❌ |
| 地图 | ✅ | ❌ |
| 赛场动画（气球、烟花） | ✅ | ❌ |
| 多屏 / 分屏 | ⚠️ 官方只支持四分区，无法两画面同屏 | ✅ 网页天然支持 |
| 换画面成本 | ❌ 重启进程，黑屏 30~40s | ✅ 瞬时 |

## 结论

如果目标只是「放个榜」，XCPCIO 更合适：现成、好看、网页。

但你要的是 **ICPC Tools 那套赛场观感** —— 判题队列、一血、题目汇总、工位倒计时、
滚榜、校徽墙。这些 XCPCIO **一个都没有**，抄不到轮子，只能自己实现。

所以 Scorewall 的定位是明确的：

> **把 ICPC Tools 的 75 个画面里「赛场需要的十来个」，用网页重做一遍，
> 顺带修掉它换画面黑屏、分屏困难、缓存/字体坑这些毛病。**
